# Talk to Me 🤟

(Talk to Me)** is a web application designed to bridge the communication gap with deaf individuals by converting **voice to sign language** and **sign language to voice** in real time.
---

## 🚀 Features

- 🎙️ **Real-time Voice to Sign Language Conversion**  
  Converts spoken words into animated sign language for clear communication.

- ✋ **Sign Language to Voice Conversion** *(in development)*  
  Detects hand gestures and converts them into spoken words.

- 🌐 **User-friendly Interface**  
  Simple and intuitive design that allows anyone to use the app easily.

- 💬 **Supports Arabic & English**  
  Recognizes and processes both Arabic and English voices.

---

## 🧠 Technologies Used

- **Python (بايثون)** – Backend logic  
- **Flask (فلاسْك)** – Web framework  
- **Vosk (فوسك)** – Offline speech recognition engine  
- **HTML, CSS, JavaScript** – Frontend interface  
- **JSON** – Data exchange format  
- **Bootstrap** – Responsive layout and design
